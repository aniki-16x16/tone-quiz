# 音题 · Tone Quiz

通过单音与和弦的级数答题练习，建立相对级数与键盘音高之间的直觉联系；和弦根音和斜线低音都用级数出题。

- 自选主音，支持自然大调和自然小调。
- 基础练习调内音，进阶加入调外音，保留 ♭3、♯9 等音程写法。
- 电脑可使用鼠标或 MIDI 键盘作答；手机支持触控。
- 电钢琴音色，可听主音作为参考，也可关闭答题声音。
- 自动或手动切题，实时查看首次作答正确率和连对次数。
- 自定义 RNG 配合打乱题袋均衡出题：每轮覆盖全部音高／根音，同类写法、和弦性质与转位也轮流覆盖。
- PC 通过左上角抽屉切换单音／和弦练习；和弦练习必须连接 MIDI，显示 C2–C5 的三八度键盘。
- 和弦题库分四档：调内三／七和弦、进阶和弦、常见爵士扩展、变化 tension。第二档起可独立开关调外根音，开启时覆盖十二个根音级数。只检查最低音和构成音；未按齐先等待，非构成音才报错。

选择调式和难度，看中央的级数，回答对应的音即可。练习不区分八度；答错会留在原题，直到答对，不提供答案提示。
